# Sotto Voce: The Cut - Glass Box

**Team Produktlicht** (René Hillers, Mehmet Piochacz-Barutcu) - 2026 Epic AI MegaJam, Unreal Engine 5.8.
Two people without game-dev experience built a stealth game in a Paris opera house, 1891, in one week - with
several Claude instances working as departments (project + code, art, music, test harness), each in its own role.

This repository is the **public record of how the game was planned, decided and built with AI**. It holds the
documentation only; the game project itself (C++, Unreal content) lives in the team's private Diversion repository
and will be mirrored after the jam. Links into source files therefore do not resolve here.

- Trailer / gameplay video: https://youtu.be/2YIpdvosupo
- The game on itch.io (Windows download): https://rharness.itch.io/sotto-voce-the-cut
