# Laws - megajam

The project's own laws. They add to the Zentrale laws (`organisation/GESETZE.md`); a project law takes
precedence over a Zentrale law unless that law is marked inviolable.

Format per law: id, the rule (what to do), why, origin (decision AND date), how it is checked.
