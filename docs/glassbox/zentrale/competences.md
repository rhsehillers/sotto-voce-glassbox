# Competences - megajam

What the PM decides without asking. Changes only with the user's release; the origin names the decision.

Levels:
- **ask** - decision draft to the user, continue with independent work meanwhile
- **report** - decide, one line under `## PM decisions` in `decisions.md`, AND name it in the next status report; the user can turn it back
- **free** - decide, THEN one line under `## PM decisions` in `decisions.md`
